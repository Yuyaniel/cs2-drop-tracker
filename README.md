# CS2 掉落记录（CS2 Drop Tracker）

一个纯前端的 CS2 每周掉落记录小工具：记录每周掉落的武器箱/皮肤，手动标价，按自定义周期（期）统计价值与掉落次数。

## 功能

- 📅 **日历视图**：本期日期胶囊高亮、今天圆形标记、距下期倒计时
- 🗂️ **总打卡框**：各期打卡记录（最新期在上），每期独立卡片边框
- ⚡ **快捷打卡**：内置常见武器箱图片，点选即填，日期按期分组可选
- 📊 **统计页**：累计总价值、各武器箱掉落次数、按类型/品质分布、各期掉落价值（按年查看）
- 💾 **数据管理**：JSON 备份导入/导出、CSV 导出、清空数据（localStorage 本地存储）

## 使用

纯静态页面，无需构建、无任何依赖：

```bash
# 方式一：直接双击打开
web/index.html

# 方式二：本地静态服务器
cd web && python -m http.server 8123
# 浏览器访问 http://127.0.0.1:8123/
```

## 自定义掉落周期

进入「⚙ 周期设置」可配置：

- **第 1 期起始日期**：你的掉落周期锚点（如 2025-04-02，与 CS2 每周三重置对齐）
- **每期天数**：默认 7 天

之后所有期自动按周期类推，每期显示「起始日 ~ 起始日+6」，重置日当天掉的箱子归新一期。

## 添加新武器箱图片

1. 把图片放入 `web/img/`（建议英文文件名，如 `newcase.png`）
2. 在 `web/js/items.js` 的 `ITEM_LIBRARY` 中添加条目：
   ```js
   { name: "新武器箱", alias: "New Case", img: "img/newcase.png", cat: "case" },
   ```
3. 重新生成内嵌图片（保证无 `img/` 目录时图片也能显示）：
   ```bash
   node tools/build-images.js
   ```

## 目录结构

```
web/
├── index.html          # 页面
├── css/style.css       # 样式（深色 CS2 橙主题）
├── js/
│   ├── app.js          # 主逻辑（周期/日历/统计/导入导出）
│   ├── items.js        # 物品名称库（含图片路径）
│   └── images.js       # 箱子图片 data URI 映射（脚本生成，勿手改）
├── img/                # 箱子图片源文件
└── tools/
    └── build-images.js # 重新生成 images.js 的脚本
```

## 技术

纯 HTML/CSS/JS，无框架、无构建、无运行时依赖；数据存 localStorage。
